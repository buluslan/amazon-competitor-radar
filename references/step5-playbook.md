# ⑤ 打法总表汇总执行细则

> 定位：这份文件管第五步怎么把拍板后的名单变成一张能拿去执行的打法总表。它是整个识别流程的最后一步，不是深度拆解报告——每个核心对标竞品一节 ≤20 行，四板块各用三问式小结，跨方案竞品每家 ≤3 段。要把某个竞品逐板块完整深拆，有专门的工具做，这一步不越界。

## 一、开始前确认输入

手上应有三样东西（都来自前四步，缺了先回去补）：

1. ④拍板后的核心对标名单——可能为空，空了走第六节分支一
2. ③分出来的跨方案竞品名单
3. ④收集的"我的产品定位一句话"（如"面向新手的高性价比 XX"）——"不能抄"的原因要贴着你的资源和定位说，不是只看竞品多强

另外两样要接着用，别弄丢：②候选池里每个 ASIN"重叠的具体词"明细（跨方案分析要用）；我的 Listing（④已经拉过就用现成的，"给我的动作"要落到我的页面上，得有对比基准）。

## 二、数据获取（每个核心对标竞品拉一次）

| 要拉什么 | 具体内容 | 拉不到怎么办 |
|---|---|---|
| 完整 Listing | 标题、五点、A+ 或详情文案 | A+ 拉不到就用五点加详情文案接着分析，标注 [A+ 缺失] |
| 价格与促销 | 当前价格、促销/优惠信息 | 促销信息没有就只分析价格，标 [缺失] |
| 评论 | 最新评论尽量 100 条，差评必须包含 | 接口没有评论能力 → 标 [缺失]，评论板块整体降级，不硬抓 |
| 销量或排名趋势 | 接口有就拉 | 没有 → 标 [缺失]，对应分析点直接跳过 |

跨方案竞品不拉评论、不拉销量趋势——它只做切入分析，标题五点够用。

按需拉取：走到第五步的竞品才拉，前四步被踢掉的不拉。字段级怎么调、评论兜底细节见 data-fallback.md，这里不重复。

## 三、核心对标竞品：四板块 × 三问式小结

每个核心对标竞品单独一节，**整节 ≤20 行**（写超了就是往深拆滑，砍）。四个板块，每板块先用两三行写清从数据里看到了什么，最后收成三问式小结：

- **值得抄的**：必须带前提条件——它有什么我没有的资源和背书（认证、专利、人群基础、价格空间）。不带前提的"值得抄"禁止出现
- **不能抄的**：必须带原因
- **给我的动作**：一条具体到可执行的动作

### 板块一 文案打法

看什么：标题策略（主打词选择与词序、品牌位、修饰词重点）；卖点结构（五点的类型构成与排序逻辑，它主打什么）；关键词埋设（哪些词出现在哪些位置、权重怎么分）。

### 板块二 视觉打法

看什么：主图策略与图片组的叙事顺序（第几张讲什么、按什么顺序推进）；视觉差异点（它跟常见做法不同在哪，这个差异在帮买家做什么决定）。

### 板块三 评论洞察

看什么：好评 Top3 理由（每条附一条代表性摘句）；差评 Top3 问题（每条附摘句）；需求缺口（差评暴露的未满足需求，我怎么用——产品改进还是文案占位）。

评论 [缺失] 时本板块整体降级：写明"评论未取到，本板块跳过"，不凭印象补"用户反馈"。

### 板块四 市场动作

看什么：价格带站位与促销节奏（有数据时）；评分数与评分分布的含义（它处在信任积累的哪个阶段）；值得盯防的动态（有数据时）。

## 四、跨方案竞品：切入分析（每家 ≤3 段）

跨方案竞品不比文案——产品形态都不同，比文案没有意义。每家只回答一个问题：**它用什么方式切进这个场景。**

- 关键词选择：它吃的是哪个场景词——直接用②候选池里它那条"重叠的具体词"明细，不重新查
- 人群话术：它讲给谁听
- 信任构建：它凭什么被信任

最后一句回答：**我能借它的切入思路吗**——借的是思路（它怎么挑词、怎么讲话、怎么建立信任），不是抄它的产品方案。

## 五、打法总表汇总

所有竞品分析完，最后必须有一张总表收尾，列定义固定：

| 竞品 ASIN | 类型 | 值得抄的 | 不能抄的（原因） | 给我的具体动作建议 |

- 类型填：核心对标 / 跨方案 / 只防不学（只防不学两种来源：分支一的空名单场景，和④打分结论为只防不学的——后者进总表供盯防参考，值得抄填"无"、动作建议写盯防类）
- 动作建议必须具体到可直接执行：
  - 正例："标题把场景词 X 提到第 2 位""五点第 2 条正面回应差评高频问题 Y"
  - 反例（禁止）："优化标题""加强视觉""提升转化"——没有动作的空话一条都不许出现

## 六、两个分支

**分支一：核心对标名单为空**（④拍板后一个核心对标都没有）

- 只跑第四节的跨方案切入分析
- 打法总表全部走"只防不学"行——盯价格和动作，不学文案：值得抄的填"无"，不能抄的写原因（差在哪个维度），动作建议只写盯防类（盯它的价格变动、上新、页面调整）

**分支二：核心对标名单超过 3 个**

- 先停下来问用户："核心对标有 N 个，是拆前 3 个还是全拆？全拆耗时会多"
- 用户拍了优先级再开跑，不自作主张截断

## 七、红线

1. 所有判断基于拉到的真实数据（Listing 原文、评论原文、价格数据），禁止凭对该品类的记忆编造"用户反馈"或"市场趋势"
2. "值得抄"必带前提条件，"不能抄"必带原因——无理由结论禁止
3. 区分事实与推断："它在做××打法"是证据说的，"它可能想××"是你的推断，推断必须标明
4. 分析深度服从数据质量：数据不足的板块宁可写短，不可编内容凑长度
5. 总表交付即停——它是给用户拿去执行的清单，这一步不往下延伸做执行

## 输出前自检

- [ ] 每个核心对标竞品一节 ≤20 行，四个板块各有三问式小结
- [ ] 每个跨方案竞品 ≤3 段
- [ ] 总表每一行的"值得抄 / 不能抄 / 动作建议"都有内容，没有空格
- [ ] 每条"值得抄"带前提条件，每条"不能抄"带原因
- [ ] 评论等 [缺失] 数据的板块已注明降级，没有假装分析过
- [ ] 动作建议里没有"优化标题""加强视觉"式空话
